# Engineering skills

## User-invoked

- [grill-with-docs](grill-with-docs/SKILL.md) — Sharpen a plan or design through an interview while recording glossary entries and decisions.
- [implement-spec](implement-spec/SKILL.md) — Implement a spec and its associated tickets.
- [setup-my-skills](setup-my-skills/SKILL.md) — Configure a repository's issue tracker, triage labels, and domain documentation layout.
- [to-spec](to-spec/SKILL.md) — Synthesize the current conversation into a spec and publish it to the issue tracker.
- [to-tickets](to-tickets/SKILL.md) — Break a plan or spec into tracer-bullet tickets with blocking relationships.
- [triage](triage/SKILL.md) — Categorize and verify issues and external pull requests, and prepare agent-ready briefs.
- [wayfinder](wayfinder/SKILL.md) — Map large efforts into decision tickets and resolve them incrementally.

## Model-invoked

- [code-philosophy](code-philosophy/SKILL.md) — Apply principles for robust internal logic and data flow.
- [code-review](code-review/SKILL.md) — Review code using severity classifications and confidence thresholds.
- [domain-modeling](domain-modeling/SKILL.md) — Develop a project's domain terminology, glossary, and architectural decisions.
- [frontend-design](frontend-design/SKILL.md) — Create distinctive, production-grade frontend interfaces.
- [frontend-philosophy](frontend-philosophy/SKILL.md) — Apply visual and UI design principles.
- [plan-review](plan-review/SKILL.md) — Review implementation plans against quality criteria.
- [prototype](prototype/SKILL.md) — Build a throwaway prototype to explore a logic or UI design question.
- [tdd](tdd/SKILL.md) — Develop features and fixes test-first through incremental red–green cycles.
